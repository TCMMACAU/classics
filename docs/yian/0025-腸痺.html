腸痺

臨證指南醫案 · 卷三

← 上一篇 下一篇 →

1張 食進脘中難下。大便氣塞不爽。腸中收痛。此為腸痺。（肺氣不開降）　大杏仁 枇杷葉 川鬱金 土栝蔞皮 山梔 香豉病人閱讀頁
2夏（二十） 食下 脹。旬日得一更衣。腸胃皆腑。以通為用。丹溪每治腸痺。必開肺氣。　謂表裡相應治法。　杏仁 紫菀 冬葵子 桑葉 土栝蔞皮病人閱讀頁
3又 腸痺開肺不效。用更衣丸三錢。病人閱讀頁
4吳 身重不能轉移。尻髀板著。必得撫摩少安。大便不通。小溲短少。不飢少飲。此時序溼邪。蒸鬱化熱。阻於氣分。經腑氣隧皆阻。病名溼痺。　木防己（一錢） 杏仁（二錢） 川桂枝（一錢） 石膏（三錢研） 桑葉（一錢） 丹皮（一錢）病人閱讀頁
5又 舌白。不渴不飢。大便經旬不解。皮膚麻癢。腹中鳴動。皆風溼化熱。阻遏氣分。諸經脈絡皆閉。昔丹溪謂腸痺。宜開肺氣以宣通。以氣通則溼熱自走。仿此論治。　杏仁 栝蔞皮 鬱金 枳殼汁 山梔 香豉 紫菀病人閱讀頁
6沈（二五） 溼結在氣。二陽之痺。丹溪每治在肺。肺氣化。則便自通。　紫菀 杏仁 枇杷葉 土栝蔞皮 鬱金 山梔皮 枳殼汁 桔梗汁病人閱讀頁
7蔣（三一） 肺痺。鼻淵。胸滿。目痛。便阻。用辛潤自上宣下法。　紫菀 杏仁 栝蔞皮 山梔 香豉 白蔻仁病人閱讀頁
8董 高年瘧後。內傷食物。腑氣阻痺。濁攻腹痛。二便至今不通。診脈右部弦搏。渴思冷凍飲料。昔丹溪大小腸氣閉於下。每每開提肺竅。內經謂肺主一身氣化。天氣降。斯雲霧清。而諸竅皆為通利。若必以消食辛溫。恐胃口再傷。滋擾憂症。聖人以真氣不可破洩。老年當遵守。　紫菀 杏仁 栝蔞皮 鬱金 山梔 香豉病人閱讀頁
9又 舌赤咽乾。陽明津衰。但痰多不飢不食。小溲不爽。大便尚秘。仿古人以九竅不利。鹹推胃中不和論治。　炒半夏 竹茹 枳實 花粉 橘紅 薑汁病人閱讀頁
10葉（女） 二便不通。此陽痺。當治在肺。　紫菀 杏仁 蔞皮 鬱金 黑山梔 桔梗病人閱讀頁
12某 癉瘧肺病。未經清理。致熱邪透入營中。遂有瘀血暴下。今診舌白不渴。不能納食。大便九日不通。乃氣痺為結。宗丹溪上竅閉。則下竅不出矣。　杏仁 枇杷葉 栝蔞皮 川鬱金 香豉 苡仁病人閱讀頁
13又 用手太陰藥。即思納谷。陽明氣痺無疑。　紫菀 杏仁 枇杷葉 栝蔞皮 鬱金 黑山梔腸痺本與便閉同類。今另分一門者。欲人知腑病治髒。下病治上之法也。蓋腸痺之便閉。　較之燥屎堅結欲便不通者稍緩。故先生但開降上焦肺氣。上竅開洩。下竅自通矣。若燥屎堅閉。則有三承氣。潤腸丸。通幽湯。及溫脾湯之類主之。然餘謂便閉之症。傷寒門中。當急下之條無幾。餘皆感六淫之邪。病後而成者為多。斯時胃氣未復。元氣已虛。若遽用下藥。於理難進。莫若外治之法為穩。用蜜煎導法。設不通爽。虛者間二三日再導。餘見有漸導漸去燥糞五六枚。或七八枚。直至二旬以外第七次。導去六十餘枚而愈者。　此所謂下不嫌遲也。學人不可忽諸。（華玉堂）病人閱讀頁

傷寒論、金匱要略方論用宋本通行條文；內經為素問、靈樞分篇；神農本草經用孫星衍輯本。本經疏證含鄒澍疏證、續疏、序疏要。臨證指南醫案按葉氏原門分案。醫學衷中參西錄為張錫純書，分醫方、藥物、醫論、醫話、醫案。金匱要略心典為尤怡注，分序、卷上、卷中、卷下；未收雜療、禽獸、果實三篇。溫病條辨為吳瑭書，分上中下焦，並雜說、解產難、解兒難。四聖心源為黃元御書。隨息居飲食譜為王士雄食療譜，分水飲、穀食、調和、蔬食、果食、毛羽、鱗介。供閱讀檢索，不是處方依據。新增類經、醫學心悟、脾胃論、醫宗金鑒、景岳全書，來源皆為維基文庫公有領域古籍頁（四庫全書本用於類經、景岳全書、醫宗金鑒）。
