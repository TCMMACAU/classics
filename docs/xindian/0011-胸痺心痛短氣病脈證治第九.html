胸痺心痛短氣病脈證治第九

金匱要略心典 · 卷上

← 上一篇 下一篇 →

1師曰。夫脈當取太過不及。陽微陰弦。即胸痺而痛。所以然者。責其極虛也。今陽虛知在上焦。所以胸痺。心痛者。以其陰弦故也。病人閱讀頁
2陽微、陽不足也。陰弦、陰太過也。陽主開。陰主閉。陽虛而陰乾之。即胸痺而痛。痺者閉也。病人閱讀頁
3夫上焦為陽之位。而微脈為虛之甚。故曰責其極虛。以虛陽而受陰邪之擊。故為心痛。病人閱讀頁
4平人無寒熱。短氣不足以息者。實也。病人閱讀頁
5平人、素無疾之人也。無寒熱、無新邪也。而乃短氣不足以息。當是裡氣暴實。或痰、或食、或飲。礙其升降之氣而然。蓋短氣有從素虛宿疾而來者。有從新邪暴遏而得者。二端並否。其為裡實無疑。此審因察病之法也。病人閱讀頁
6胸痺之病。喘息咳唾。胸背痛。短氣。寸口脈沉而遲。關上小緊數。栝蔞薤白白酒湯主之。病人閱讀頁
7胸中陽也。而反痺。則陽不用矣。陽不用。則氣之上下不相順接。前後不能貫通。而喘息、咳唾、胸背痛、短氣等證見矣。更審其脈。寸口亦陽也。而沉遲。則等於微矣。關上小緊。亦陰弦之意。而反數者。陽氣失位。陰反得而主之。易所謂陰凝於陽。書所謂牝雞之晨也。是當以通胸中之陽為主。病人閱讀頁
8薤白、白酒。辛以開痺。溫以行陽。栝蔞實者。以陽痺之處。必有痰濁阻其間耳。病人閱讀頁
9栝蔞薤白白酒湯方栝蔞實（一枚搗）薤白（半升）白酒（七升）病人閱讀頁
10上三味。同煮。取二升。分溫再服。病人閱讀頁
11胸痺不得臥。心痛徹背者。栝蔞薤白半夏湯主之。病人閱讀頁
12胸痺不得臥。是肺氣上而不下也。心痛徹背。是心氣塞而不和也。其痺為尤甚矣。所以然者。有痰飲以為之援也。故於胸痺藥中。加半夏以逐痰飲。病人閱讀頁
13栝蔞薤白半夏湯方栝蔞實（一枚搗）薤白（三兩）半夏（半升）白酒（一斗）病人閱讀頁
14上四味。同煮。取四升。溫服一升。日三服。病人閱讀頁
15胸痺。心中痞氣。氣結在胸。胸滿。脅下逆搶心。枳實薤白桂枝湯主之。人參湯亦主之。病人閱讀頁
16心中痞氣。氣痺而成痞也。脅下逆搶心。氣逆不降。將為中之害也。是宜急通其痞結之氣。否則速復其不振之陽。蓋去邪之實。即以安正。養陽之虛。即以逐陰。是在審其病之久暫。與氣之虛實而決之。病人閱讀頁
17栝蔞薤白桂枝湯方枳實（四枚）薤白（半升）桂枝（一兩）厚朴（四兩）栝蔞實（一枚搗）病人閱讀頁
18上五味。以水五升。先煮枳實、厚朴。取二升。去滓。內諸藥。煮數沸。分溫三服。病人閱讀頁
19人參湯方人參甘草乾薑白朮（各三兩）病人閱讀頁
20上四味。以水八升。煮取三升。溫服一升。日三服。病人閱讀頁
21胸痺。胸中氣塞。短氣。茯苓杏仁甘草湯主之。橘枳生薑湯亦主之。病人閱讀頁
22此亦氣閉氣逆之證。視前條為稍緩矣。二方皆下氣散結之劑。而有甘淡苦辛之異。亦在酌其強弱而用之。病人閱讀頁
23茯苓杏仁甘草湯方茯苓（三兩）杏仁（五十個）甘草（一兩）病人閱讀頁
24上三味。以水一斗。煮取五升。溫服一升。日三服。不瘥。更服。病人閱讀頁
25橘枳生薑湯方橘皮（一斤）枳實（三兩）生薑（半斤）病人閱讀頁
26上三味。以水五升。煮取二升。分溫再服。病人閱讀頁
27胸痺緩急者。薏苡附子散主之。病人閱讀頁
28陽氣者。精則養神。柔則養筋。陽痺不用。則筋失養而或緩或急。所謂大筋軟短。小筋弛長者是也。故以薏苡仁舒筋脈。附子通陽痺。病人閱讀頁
29薏苡附子散方薏苡仁（十五兩）大附子（十枚炮）病人閱讀頁
30上二味。杵為散。服方寸匕。日三服。病人閱讀頁
31心中痞。諸逆。心懸痛。桂枝生薑枳實湯主之。病人閱讀頁
32諸逆。該痰飲、客氣而言。心懸痛。謂如懸物動搖而痛。逆氣使然也。桂枝、枳實、生薑。辛以散逆。苦以洩痞。溫以祛寒也。病人閱讀頁
33桂枝生薑枳實湯方桂枝生薑（各三兩）枳實（五兩）病人閱讀頁
34上三味。以水六升。煮取三升。分溫三服。病人閱讀頁
35心痛徹背。背痛徹心。烏頭赤石脂丸主之。病人閱讀頁
36心背徹痛。陰寒之氣。遍滿陽位。故前後牽引作痛。沈氏雲。邪感心包。氣應外俞。則心痛徹背。病人閱讀頁
37邪襲背俞。氣從內走。則背痛徹心。俞髒相通。內外之氣相引。則心痛徹背。背痛徹心。即經所謂寒氣客於背俞之脈。其俞注於心。故相引而痛是也。烏、附、椒、姜。同力協濟。以振陽氣而逐陰邪。病人閱讀頁
38取赤石脂者。所以安心氣也。病人閱讀頁
39烏頭赤石脂丸方烏頭（一分炮）蜀椒乾薑（各一兩）附子（半兩）赤石脂（一兩）病人閱讀頁
40上五味。末之。蜜丸如桐子大。先食服一丸。日三服。不知稍加服。病人閱讀頁
41附子（三兩炮）生野狼牙巴豆（去皮熬研如膏）乾薑吳茱萸人參（各一兩）病人閱讀頁
42上六味。末之。煉蜜丸如梧子大。酒下。強人初服三丸。日三服。弱者二丸。兼治卒中惡。腹脹。病人閱讀頁
43口不能言。又治連年積冷。流注心胸痛。並冷衝上氣。落馬墜車血疾等皆主之。忌口如常法。病人閱讀頁
44按、九痛者。一蟲、二注、三風、四悸、五食、六飲、七冷、八熱、九去來痛是也。而並以一藥治之者。豈痛雖有九。病人閱讀頁
45其因於積冷結氣所致者多耶。病人閱讀頁
