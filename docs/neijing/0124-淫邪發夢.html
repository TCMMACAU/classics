淫邪發夢

黃帝內經 · 靈樞

← 上一篇 下一篇 →

1黃帝曰：願聞淫邪泮衍，奈何？病人閱讀頁
2岐伯曰：正邪從外襲內，而未有定舍，反淫於臓，不得定處，與營衛俱行，而與魂魄飛揚，使人臥不得安而喜夢；氣淫於腑，則有餘於外，不足於內；氣淫於臓，則有餘於內，不足於外。病人閱讀頁
3黃帝曰：有餘不足，有形乎？病人閱讀頁
4岐伯曰：陰氣盛，則夢涉大水而恐懼；陽氣盛，則夢大火而燔爇；陰陽俱盛，則夢相殺。上盛則夢飛，下盛則夢墮。甚飢則夢取，甚飽則夢予。肝氣盛，則夢怒；肺氣盛，則夢恐懼、哭泣、飛揚；心氣盛，則夢善笑恐畏；脾氣盛，則夢歌樂、身體重不舉；腎氣盛，則夢腰脊兩解不屬。凡此十二盛者，至而瀉之，立已。病人閱讀頁
5厥氣客於心，則夢見丘山煙火；客於肺，則夢飛揚，見金鐵之奇物；客於肝，則夢山林樹木；客於脾，則夢見丘陵大澤，壞屋風雨；客於腎，則夢臨淵，沒居水中；客於膀胱，則夢遊行；客於胃，則夢飲食；客於大腸，則夢田野；客於小腸，則夢聚邑衝衢；客於膽，則夢鬥訟自刳；客於陰器，則夢接內；客於項，則夢斬首；客於脛，則夢行走而不能前，及居深地窌苑中；客於股肱，則夢禮節拜起；客於胞䐈，則夢溲便。凡此十五不足者，至而補之立已也。病人閱讀頁
