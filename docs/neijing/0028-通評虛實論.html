通評虛實論

黃帝內經 · 素問

← 上一篇 下一篇 →

1黃帝問曰：何謂虛實？病人閱讀頁
2岐伯對曰：邪氣盛則實，精氣奪則虛。病人閱讀頁
3帝曰：虛實何如？病人閱讀頁
4岐伯曰：氣虛者，肺虛也。氣逆者，足寒也。非其時則生，當其時則死。餘髒皆如此。病人閱讀頁
5帝曰：何謂重實？病人閱讀頁
6岐伯曰：所謂重實者，言大熱病，氣熱脈滿，是謂重實。病人閱讀頁
7帝曰：經絡俱實何如？何以治之？病人閱讀頁
8岐伯曰：經絡皆實，是寸脈急而尺緩也，皆當治之。故曰：“滑則從，澀則逆也。”夫虛實者，皆從其物類始，故五臟骨肉，滑利可以長久也。病人閱讀頁
9帝曰：絡氣不足，經氣有餘，何如？病人閱讀頁
10岐伯曰：絡氣不足，經氣有餘者，脈口熱而尺寒也。秋冬為逆，春夏為從，治主病者。病人閱讀頁
11帝曰：經虛絡滿何如？病人閱讀頁
12岐伯曰：經虛絡滿者，尺熱滿，脈口寒澀也。此春夏死，秋冬生也。病人閱讀頁
13帝曰：治此者奈何？病人閱讀頁
14岐伯曰：絡滿經虛，灸陰刺陽；經滿絡虛，刺陰灸陽。病人閱讀頁
15帝曰：何謂重虛？病人閱讀頁
16岐伯曰：脈氣（《甲乙經》為虛）、上（《甲乙經》為氣）虛、尺虛，是為重虛。病人閱讀頁
17帝曰：何以治之？病人閱讀頁
18岐伯曰：所謂氣虛者，言無常也；尺虛者，行步恇然。脈虛者，不象陰也。如此者，滑則生，澀則死也。病人閱讀頁
19帝曰：寒氣暴上，脈滿而實，何如？病人閱讀頁
20岐伯曰：實而滑則生，實而逆則死。病人閱讀頁
21帝曰：脈實滿，手足寒，頭熱，何如？病人閱讀頁
22岐伯曰：春秋則生，冬夏則死。脈浮而澀，澀而身有熱者死。病人閱讀頁
23帝曰：其形盡滿何如？病人閱讀頁
24岐伯曰：其形盡滿者，脈急大堅，尺澀而不應也，如是者，故從則生，逆則死。病人閱讀頁
25帝曰：何謂從則生，逆則死？病人閱讀頁
26岐伯曰：所謂從者，手足溫也；所謂逆者，手足寒也。病人閱讀頁
27帝曰：乳子而病熱，脈懸小者，何如？病人閱讀頁
28岐伯曰：手足溫則生，寒則死。病人閱讀頁
29帝曰：乳子中風熱，喘鳴肩息者，脈何如？病人閱讀頁
30岐伯曰：喘鳴肩息者，脈實大也，緩則生，急則死。病人閱讀頁
31帝曰：腸澼便血，何如？病人閱讀頁
32岐伯曰：身熱則死，寒則生。病人閱讀頁
33帝曰：腸澼下白沫，何如？病人閱讀頁
34岐伯曰：脈沉則生，脈浮則死。病人閱讀頁
35帝曰：腸澼下膿血，何如？病人閱讀頁
36岐伯曰：脈懸絕則死，滑大則生。病人閱讀頁
37帝曰：腸澼之屬，身不熱，脈不懸絕，何如？病人閱讀頁
38岐伯曰：滑大者曰生，懸澀者曰死，以髒期之。病人閱讀頁
39帝曰：癲疾何如？病人閱讀頁
40岐伯曰：脈搏大滑，久自已；脈小堅急，死不治。病人閱讀頁
41帝曰：癲疾之脈，虛實何如？病人閱讀頁
42岐伯曰：虛則可治，實則死。病人閱讀頁
43帝曰：消癉虛實何如？病人閱讀頁
44岐伯曰：脈實大，病久可治；脈懸小堅，病久不可治。病人閱讀頁
45帝曰：形度、骨度、脈度、筋度，何以知其度也？（讀注：此處有問無答，且與上下文不搭，明清醫家已經認為此處是錯簡而形成的綴文。）病人閱讀頁
46帝曰：春亟治經絡，夏亟治經俞，秋亟治六腑府，冬則閉塞。閉塞者，用藥而少針石也。所謂少針石者，非癰疽之謂也。癰疽不得頃時回，癰不知所，按之不應手，乍來乍已，刺手太陰傍三痏，與纓脈各二。掖癰大熱，刺足少陽五，刺而熱不止，刺手心主三，刺手太陰經絡者，大骨之會各三。暴癰筋軟，隨分而痛，魄汗不盡，胞氣不足，治在經俞。病人閱讀頁
47腹暴滿，按之不下，取手太陽經絡者，胃之募也。少陰俞去脊椎三寸傍五，用圓利針。病人閱讀頁
48霍亂，刺俞旁五，足陽明及上傍三。病人閱讀頁
49刺癇驚脈五，針手太陰各五，刺經太陽五，刺手少陰經絡傍者一，足陽明一，上踝五寸刺三針。病人閱讀頁
50凡治消癉、僕擊、偏枯、痿厥、氣滿發逆，肥貴人，則高粱之疾也。隔塞閉絕，上下不通，則暴憂之病也。暴厥而聾，偏塞閉不通，內氣暴薄也。不從內外中風之病，故瘦留著也。蹠跛，寒風溼之病也。病人閱讀頁
51黃帝曰：黃疸、暴痛、癲疾、厥狂，久逆之所生也。五臟不平，六腑閉塞之所生也。頭痛耳鳴，九竅不利，腸胃之所生也。病人閱讀頁
