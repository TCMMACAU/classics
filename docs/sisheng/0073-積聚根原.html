積聚根原

四聖心源 · 卷六 雜病解中

← 上一篇 下一篇 →

1積聚者，氣血之凝瘀也。血積為癥，氣積為瘕。病人閱讀頁
2《金匱》：婦人宿有癥病，經斷未及三月，而得漏下不止，胎動在臍上者，此為癥痼害，所以血不止者，其癥不去故也。緣瘀血癥聚，不在子宮，三月胎長，與癥痼相礙，故血阻而下，是癥病之為血也。病人閱讀頁
3《傷寒》：陽明病，若中寒，不能食，小便不利，手足濈然汗出，此欲作痼瘕，必大便初硬後溏。所以然者，以胃中冷，水谷不別故也。緣寒氣凝結，水谷不消，則大便洩利，《難經》謂之大瘕洩，是瘕病之為氣也。病人閱讀頁
4癥瘕之病，多見寒熱。以氣血積聚，陽不外達，故內鬱而發熱；陰不內斂，故外束而惡寒。氣統於肺，血藏於肝，氣聚者，多下寒，血積者，多上熱。蓋離陰右降而化金水，及其成水，而又抱陽氣，故下焦不寒。氣聚則金水失其收藏，陽不下蟄，是以寒生。坎陽左升而化木火，及其成火，而又含陰精，故上焦不熱。血積則木火失其生長，陰不上根，是以熱作。病人閱讀頁
5血性溫暖而左升，至右降於金水，則化而為清涼。血之左積者，木之不溫也；血之右積者，金之不涼也。氣性清涼而右降，至左升於木火，則化而為溫暖。氣之右聚者，金之不清也；氣之左聚者，木之不暖也。而溯其原本，總原於土。己土不升，則木陷而血積；戊土不降，則金逆而氣聚。中氣健運而金木旋轉，積聚不生，癥瘕弗病也。病人閱讀頁
6化堅丸病人閱讀頁
7甘草二兩 丹皮三兩 橘皮三兩 桃仁三兩 杏仁三兩 桂枝三兩病人閱讀頁
8煉蜜、陳醋丸，酸棗大，米飲下三五丸，日二次。病人閱讀頁
9若癥瘕結硬難消，須用破堅化癖之品。內寒加巴豆、川椒，內熱加芒硝、大黃。病人閱讀頁
10積聚之病，不過氣血。左積者，血多而氣少，加鱉甲、牡蠣；右聚者，氣多而血少，加枳實、厚朴。總之，氣不得血則不行，血不得氣則不運。氣聚者，血無有不積，血積者，氣無有不聚，但有微甚之分耳。其內在臟腑者，可以丸愈，外在經絡者，以膏藥消之。病人閱讀頁
11化堅膏病人閱讀頁
12歸尾四錢 鱉甲八錢 巴豆四錢，研 黃連四錢 三稜四錢 莪術四錢 山甲一兩二錢 筋餘一錢病人閱讀頁
13以上八味，用芝麻油一斤、淨丹八兩，熬膏。病人閱讀頁
14硼砂四錢 磠砂四錢 阿魏六錢，炒，研 麝香二錢 人參四錢 三七四錢 山羊血四錢 肉桂四錢病人閱讀頁
15以上八味，研細，入膏，火化，攪勻。稍冷，傾入水盆，浸二三日，罐收，狗皮攤。病人閱讀頁
16皮硝水熱洗皮膚，令透，拭乾，生薑切搽數十次，貼膏。一切癖塊積聚，輕者一貼，重者兩貼，全消。漸貼漸小，膏漸離皮，未消之處，則膏粘不脫。病人閱讀頁
17忌一切發病諸物，惟豬、犬、鴨、鳧、有鱗河魚、菘、韮、米、面不忌。其餘海味、雞、羊、黃瓜，凡有宿根之物，皆忌。若無鱗魚、天鵝肉、母豬、蕎麥、馬齒莧，則忌之終身。犯之，病根立發。若癖塊重發，則不可救矣。病人閱讀頁
