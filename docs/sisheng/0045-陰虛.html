陰虛

四聖心源 · 卷四 勞傷解

← 上一篇 下一篇 →

1陰盛於下而生於上，火中之液，是曰陰根。陰液滋息，爰生金水。陰性沉靜，其根一生，則沉靜而親下者，性也，是以金收而水藏。而金水之收藏，全賴胃土之降，胃土右降，金收於西而水藏於北，陽氣蟄封，此木火生長之根本也。病人閱讀頁
2胃土不降，金水失收藏之政，君相二火洩露而升炎，心液消耗，則上熱而病陰虛。病人閱讀頁
3人知其金水之虧，而不知其胃土之弱。胃以陽體而含陰魄，旺則氣化而陰生。以氣統於肺而實化於胃，肺氣清降而產陰精，即胃土之右轉而變化者也。是宜降肺胃助收藏，未可徒滋心液也。病人閱讀頁
4地魄湯病人閱讀頁
5甘草二錢，炙 半夏三錢，制 麥冬三錢，去心 芍藥三錢 五味子一錢，研 元參三錢 牡蠣三錢，煅，研病人閱讀頁
6煎大半杯，溫服。病人閱讀頁
7水為陰，而陰生於肺胃，胃逆而肺金不斂，君相升洩，則心液消亡，而陰無生化之原。麥冬、芍藥，雙清君相之火，半夏、五味，降攝肺胃之逆，元參清金而益水，牡蠣斂神而藏精。病人閱讀頁
8若熱傷肺氣，不能化水，則用人參、黃芪，益氣生水，以培陰精之原。此補陰之法也。病人閱讀頁

傷寒論、金匱要略方論用宋本通行條文；內經為素問、靈樞分篇；神農本草經用孫星衍輯本。本經疏證含鄒澍疏證、續疏、序疏要。臨證指南醫案按葉氏原門分案。醫學衷中參西錄為張錫純書，分醫方、藥物、醫論、醫話、醫案。金匱要略心典為尤怡注，分序、卷上、卷中、卷下；未收雜療、禽獸、果實三篇。溫病條辨為吳瑭書，分上中下焦，並雜說、解產難、解兒難。四聖心源為黃元御書。隨息居飲食譜為王士雄食療譜，分水飲、穀食、調和、蔬食、果食、毛羽、鱗介。供閱讀檢索，不是處方依據。新增類經、醫學心悟、脾胃論、醫宗金鑒、景岳全書，來源皆為維基文庫公有領域古籍頁（四庫全書本用於類經、景岳全書、醫宗金鑒）。
