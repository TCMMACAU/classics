桂枝加桂湯方

醫宗金鑒 · 訂正傷寒論注

← 上一篇 下一篇 →

1於桂枝湯方內更加桂二兩成五兩餘依桂枝湯法〔注〕集解徐彬曰此乃太陽風邪因燒鍼令汗復感於寒邪從太陽之府膀胱襲入相合之腎藏而作奔豚故仍從太陽之例用桂枝全方倍加桂者以內瀉陰氣兼驅外邪也太陽病以火燻之不得汗其人必躁到經不解必圊血名為火邪〔注〕註火燻古劫汗法也即今火炕溫覆取汗之法太陽病以火燻之不得汗其人必內熱躁甚陰液愈傷陽不得陰無從化汗故反致不解也其火襲入陰中傷其陰絡廹血下行故必圊血也命名火邪示人以當治火邪不必治圊血也〔注〕集註方有執曰躁手足疾動也到猶言反也謂徒躁擾而反不得解也汗為血之液血得熱則行火性大熱既不得汗則血必橫溢所以必圊血也程應旄曰太陽病以火燻之取汗竟不得汗其液之素少可知葢陽不得陰則無從化汗也陰虛被火熱無從出故其人躁擾不寧也衇浮熱甚反灸之此為實實以虛治因火而動故咽燥而吐血〔注〕註衇浮熱甚實熱在表也無灸之之理而反灸之此為實實謂其誤以實為虛也故熱因火動其勢炎炎致咽燥而吐血必矣葢上條火傷陰分廹血下行故令圊血此條火傷陽分廹血上行故吐血也病人閱讀頁
2〔注〕集註程應旄曰表實有熱誤認虛寒而用灸法熱無從泄因火而動自然內攻邪束於外火攻於內肺金被傷故咽燥而吐血汪琥曰表有風熱而反灸是以實作虛治也微數之衇甚不可灸因火爲邪則為煩逆追虛逐實血散衇中火氣雖微內攻有力焦骨傷筋血難復也〔注〕註微數之衇乃陰虛血少之證斷不可灸若誤灸之艾火內攻為煩為逆煩者陰為陽擾也逆者追虛逐實也陰本虛而加以火則愈虛是為追虛陽本實而加以火則愈實是為逐實然血已耗散衇中艾火之氣雖微而內攻有力矣故致焦骨傷筋血難復也〔注〕集註喻昌曰衇微而數陰虛多熱之徵也此而灸之則虛者愈虛熱者愈熱不致傷殘不止矣程應旄曰若血少陰虛之人衇見微數尤不可灸以血主濡之主潤筋骨也若失其所濡則火之所至其骨必焦其筋必損內傷其陰未有不流散於經衇者也榮氣微者加燒鍼則血留不行更發熱而躁煩也〔注〕註榮氣微者榮血虛微也榮血既已虛微若誤加燒鍼則榮血涸留而無所行也豈止焦骨傷筋而已哉所以更發熱而躁煩也病人閱讀頁
3〔注〕集註程知曰言榮微忌燒鍼也陰虛則內熱若加燒鍼以助陽則兩熱相合而榮血不行必更外發熱而內煩躁也唐不巖曰其始也雖微流燒鍼以逼之也其既也留而不行燒鍼以竭之也張璐曰火為陽邪必傷隂血治此者當以救隂為主衇浮宜以汗解用火灸之邪無從出因火而盛病從腰以下必重而痺名火逆也〔注〕註衇浮表邪宜以汗解誤用火灸傷其血液不能作汗反令表邪無所從出以致邪因火盛外不焦骨傷筋內不吐衂圊血而病腰以下重痺者必其人素有濕邪在下故從濕化也重者著也重著不移也然不以痺名者以非風寒濕之痺乃因火逆不相交通故名火逆也〔注〕集註方有執曰痺濕病也因火逆治火邪夾陽邪而上逆陽不下通隂不用事化不行而水不得泄故濕著下體而重痺也程應旄曰衇浮在表汗解為宜矣因火灸之不能得汗則邪無出路因火而盛即不焦骨傷筋而火阻其邪陰氣漸竭下焦乃榮血所治榮氣竭而不運必重著而為痺名曰火逆示人慾治其痺宜先治其火也形作傷寒其衇不□緊而弱弱者必渴被火者必讝語弱者發熱衇浮解之當汗出愈〔注〕按三弱字當俱是數字若是弱字熱從何有不但文義不屬且論中並無此說病人閱讀頁
4〔注〕註形作傷寒者言其病形作傷寒之狀也但其衇不□緊而數數者熱也衇浮數熱在表太陽證也沉數熱在裏陽明證也數衇為熱熱入陽明故必口渴若被火刦其熱更甚故必讝語衇數之病雖皆發熱然其施治不無別焉若衇浮數發熱解之當以汗汗出可愈宜大青龍湯衇沉數發熱解之當以下下之可愈宜調胃承氣湯若衇數無表裏證惟發熱而渴讝語者不可汗下宜白虎湯黃連解毒湯清之可也傷寒衇浮醫以火逼刦之亡陽必驚狂起臥不安者桂枝去芍藥加蜀漆龍骨牡蠣救逆湯主之〔注〕註傷寒衇浮醫不用麻桂之藥而以火刦取汗汗過亡陽故見驚狂起臥不安之證蓋由火刦之誤熱氣從心且大脫津液神明失倚也然不用附子四逆軰者以其爲火刦亡陽也宜以桂枝湯去芍藥加蜀漆龍骨牡蠣救逆湯主之去芍藥者恐其隂性遲滯兼制桂枝不能迅走其外反失救急之㫖況既加龍蠣之固脫亦不湏芍藥之酸收也蜀漆氣寒味苦寒能勝熱苦能降逆火邪錯逆在所必需也病人閱讀頁
5〔注〕集註喻昌曰篇中誤服大青龍湯厥逆筋愓肉瞤而亡陽者乃汗多所致故用真武湯救之此以火廹刼而亡陽者乃方寸元陽之神被火廹刦而飛騰散亂故驚狂起臥不安有如此者少緩湏臾神丹莫挽矣故以此湯救之蓋陽神散亂當求之於陽桂枝湯陽藥也然必去芍藥之隂歛始得疾趨以達於陽位更加蜀漆者緣蜀漆之性最急又加龍骨牡蠣有形之骨屬為之舟楫以載神而返其宅也桂枝去芍藥加蜀漆龍骨牡蠣救逆湯方病人閱讀頁
