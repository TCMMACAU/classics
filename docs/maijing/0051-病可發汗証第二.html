病可發汗証第二

脈經 · 脈經卷七

← 上一篇 下一篇 →

1大法，春夏宜發汗。病人閱讀頁
2凡發汗，欲令手足皆周至， 一時間益佳，但不欲如水流離。若病不解，當重發汗。汗多則亡陽，陽虛不得重發 汗也。病人閱讀頁
3凡服湯藥發汗，中病便止，不必盡劑也。病人閱讀頁
4凡云可發汗而無湯者，丸散亦可用，要以汗出為解，然不如湯隨証良。病人閱讀頁
5太陽病，外証未解，其脈浮弱，當以汗解，宜桂枝湯。病人閱讀頁
6太陽病，脈浮而數者，可發其汗，屬桂枝湯証。病人閱讀頁
7陽明病，脈遲，汗出多，微惡寒，表為未解，可發其汗，屬桂枝湯証。夫病脈浮大，問病者，言但堅耳。設利者為虛，大逆。堅為實，汗出而解，何以故？脈浮，當以汗解。病人閱讀頁
8傷寒，其脈不弦緊而弱，弱者必渴，被火必譫語。弱者發熱脈浮，解之，當汗出癒。病人閱讀頁
9病者煩熱，汗出即解。復如瘧狀，日晡所發熱，此屬陽明。脈浮虛者，當發其汗，屬桂枝湯證。病人閱讀頁
10病常自汗出，此為榮氣和，榮氣和而外不解，此衛不和也。榮行脈中，為陰，主內；衛行脈外，為陽，主外。復發其汗，衛和則癒，屬桂枝湯証。病人閱讀頁
11病人臟無他病，時發熱自汗出，而不癒，此衛氣不和也。先其時發汗即癒，屬桂枝湯證。病人閱讀頁
12脈浮而緊，浮則為風，緊則為寒，風則傷衛，寒則傷榮，榮衛俱病，骨節 煩疼，可發其汗，宜麻黃湯。病人閱讀頁
13太陽病不解，熱結膀胱，其人如狂，血必自下，下者即癒。其外未解者，尚未可攻，當先解其外，屬桂枝湯証。病人閱讀頁
14太陽病，下之，微喘者，表未解故也。屬桂枝加濃朴杏子湯証。病人閱讀頁
15傷寒，脈浮緊，不發其汗，因衄，屬麻黃湯証。病人閱讀頁
16陽明病，脈浮，無汗，其人必喘。發其汗則癒，屬麻黃湯証。病人閱讀頁
17太陰病，脈浮者，可發其汗，屬桂枝湯証。病人閱讀頁
18太陽病，脈浮緊，無汗而發熱，其身疼痛，八、九日不解，表候續在，此當發其汗，服湯微除。發煩目瞑，劇者必衄，衄乃解。所以然者，陽氣重故也。屬麻黃湯証。病人閱讀頁
19脈浮者，病在表，可發其汗，屬桂枝湯証。病人閱讀頁
20傷寒不大便六、七日，頭痛有熱，與承氣湯，其大便反青（一作小便清者）。此為不在裡故在表也，當發其汗。頭痛 者，必衄，屬桂枝湯証。病人閱讀頁
21下利後，身體疼痛，清便自調，急當救表，宜桂枝湯。病人閱讀頁
22太陽病，頭痛發熱，汗出惡風，若惡寒，屬桂枝湯証。病人閱讀頁
23太陽中風，陽浮而陰濡弱。浮者熱自發，濡弱者汗自出，嗇嗇惡寒，淅淅惡風，翕翕發熱，鼻鳴乾嘔，屬桂枝湯証。病人閱讀頁
24太陽病，發熱汗出，此為榮弱衛強，故使汗出，欲救邪風，屬桂枝湯証。病人閱讀頁
25太陽病，下之，氣上撞，可與桂枝湯；不撞，不可與之。病人閱讀頁
26太陽病，初服桂枝湯，而反煩不解者，法當先刺風池、風府，卻與桂枝湯則癒。病人閱讀頁
27燒針令其汗，針處被寒，核起而赤者，必發賁豚。氣從少腹上撞心者，灸其核上一壯，與桂枝加桂湯。病人閱讀頁
28太陽病，項背強几，几反汗出惡風，屬桂枝加葛根湯。病人閱讀頁
29太陽病，項背強几，几無汗惡風，屬葛根湯。病人閱讀頁
30太陽與陽明合病，而自利不嘔者，屬葛根湯証。病人閱讀頁
31太陽與陽明合病，不下利，但嘔，屬葛根加半夏湯。病人閱讀頁
32太陽病，桂枝証，醫反下之，遂利不止，其脈促者，表未解，喘而汗出，屬葛根黃芩黃連湯。病人閱讀頁
33太陽病，頭痛發熱，身體疼，腰痛，骨節疼痛，惡風，無汗而喘，屬麻黃湯証。病人閱讀頁
34太陽與陽明合病，喘而胸滿，不可下也。屬麻黃湯証。病人閱讀頁
35太陽中風，脈浮緊，發熱惡寒，身體疼痛，不汗出而煩躁，頭痛，屬大青龍湯。脈微弱，汗出惡風，不可服之。服之則厥，筋惕肉，此為逆也。病人閱讀頁
36傷寒脈浮緩，其身不疼，但重，乍有輕時，無少陰証者，大青龍湯發之。病人閱讀頁
37傷寒表不解，心下有水氣，乾嘔，發熱而咳，或渴，或利，或噎，或小便不利，小腹滿，或微喘，屬小青龍湯。病人閱讀頁
38傷寒，心下有水氣，咳而微喘，發熱不渴，服湯已而渴者，此寒去，為欲解，屬小青龍湯証。病人閱讀頁
39陽明中風，脈弦浮大而短氣，腹都滿，脅下及心痛，久按之，氣不通（一作按之不痛），鼻乾，不得汗，嗜臥，一身及目悉黃，小便難，有潮熱，時時噦，耳前後腫，刺之小瘥，外不解，病過十日，脈續浮，與小柴胡湯。但浮，無餘証，與麻黃湯。不溺，腹滿加噦，不治。病人閱讀頁
40太陽病，十日以去，脈浮細，嗜臥，此為外解。設胸滿脅痛，與小柴胡湯。脈浮者，屬麻黃湯証。病人閱讀頁
41中風，往來寒熱，傷寒五、六日以後，胸脅苦滿，嘿嘿不欲飲食，煩心喜嘔，或胸中煩而不嘔，或渴，或腹中痛，或脅下痞堅，或心中悸，小便不利，或不渴，外有微熱，或咳者，屬小柴胡湯。病人閱讀頁
42傷寒四、五日，身體熱，惡風，頸項強，脅下滿，手足溫而渴，屬小柴胡湯証。病人閱讀頁
43傷寒六、七日，發熱、微惡寒，支節煩疼，微嘔，心下支結，外証未去者，屬柴胡桂枝湯。病人閱讀頁
44少陰病，得之二、三日，麻黃附子甘草湯微發汗，以二、三日無証，故微發汗也。病人閱讀頁
45脈浮，小便不利，微熱，消渴，與五苓散，利小便發汗。病人閱讀頁
