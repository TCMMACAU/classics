灸勞穴法

針灸大成 · 卷十一

← 上一篇 下一篇 →

1資生經云：久勞其狀手腳心熱，盜汗，精神困頓，骨節疼痛，初發咳嗽，漸吐膿血， 肌瘦面黃，減食少力，令身正直，用草於男左女右自腳中指尖，量過腳心下。 向上至曲瞅大紋處，截斷，卻將此草自鼻尖量，從頭正中分開髮，量至脊。 以草盡處，用墨點記，別用草一條，令病人自然合口，量闊狹，截斷。 卻將此草於墨點上，平摺兩頭，盡處量穴，灸時隨年紀，多灸一壯，如人三十歲， 灸三十一壯，累效。按此穴，合五椎兩旁，各一寸五分，心俞二穴也。心主血， 故灸之。病人閱讀頁
