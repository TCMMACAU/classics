問皮肉筋骨脈病

針灸大成 · 卷六

← 上一篇 下一篇 →

1答曰：百病所起，皆始於榮衛，然後淫於皮肉筋脈，故經言是動脈者，氣也。 所生病者，血也。先為是動，而後所生病也。由此進之，則知皮肉筋脈， 亦是後所生之病耳！是以刺法中但舉榮衛。蓋取榮衛逆順，則皮骨筋肉之治， 在其中矣，以此思之，至於部分有淺深之不同，卻要下針無過不及玅也。 ○一日皮膚，二日肌肉，三日筋骨。
