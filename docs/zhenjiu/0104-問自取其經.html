問自取其經

針灸大成 · 卷六

← 上一篇 下一篇 →

1答曰：刺虛刺實，當迎隨，補其母而瀉其子，若不虛不實者，則當經取。 謂其正經自得病，不中他邪，故自取其經也。其法右手存意持針。 左手候其穴中之氣，若氣來至如動脈狀，乃內針，要續續而入，徐徐而撞， 入榮至衛，至若得氣如鮪魚入鉤，即是病之氣也。則隨本經氣血多少，酌量取之， 略待少許，見氣盡，乃出針，如未盡，留針在門，然出針。經曰：有見如入， 有見如出，此之謂也。
