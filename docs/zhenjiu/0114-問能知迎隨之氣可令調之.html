問能知迎隨之氣可令調之

針灸大成 · 卷六

← 上一篇 下一篇 →

1答曰：迎隨之法，因其中外上下病道遙遠而設也。是故當榮衛內外之出入。 經脈上下之往來，乃可行之。夫榮衛者陰陽也。經言陽氣於四末，陰受氣於五臟， 故瀉者，先深而後淺，從引持出之，補者先淺而後深，從外推內而入之。 乃是因其陰陽內外而進退針耳，至於經脈流行之道，手三陽經，從手上頭， 手三陰經，從胸至手，足三陽經，從頭下足，足三陰經，從足入腹。 故手三陽瀉者，針芒望外，逆而迎之，補者，針芒望內，順而追之，餘皆倣此， 乃是氣血往來，而順逆行針也。大率言榮衛者，是內外之氣出入，言經脈者， 是上下之氣往來，各隨所在順逆而為刺也。故曰迎隨耳！病人閱讀頁
