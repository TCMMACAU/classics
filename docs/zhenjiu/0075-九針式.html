九針式

針灸大成 · 卷五

← 上一篇 下一篇 →

1帝曰：針之長短有數乎？岐伯對曰：一曰鑱針，取法於巾，針頭大末銳，末平半寸， 卒銳之長一寸六分；二曰圓針，取法於絮，針筩其身，而卵其鋒，針如卵形圓其末， 長一寸六分。三曰鍉針，（鍉音低）取法於黍粟之銳，長三寸半；四曰鋒針， 取法於絮，筩其身鋒其末，刃三隅，長一寸六分。五曰鈹針，取法於劍鋒，末如劍， 廣二寸半，長四寸；六曰圓利針，取法於氂，針且圓且銳，微大其末，反小其身， 又曰中身微大長一寸六分。七曰毫針，取法於毫毛，尖如蚊虻喙，長三寸六分； 八曰長針，取法於綦，針鋒利，身薄，長七寸。九曰火針，取法於鋒，針尖如挺， 其鋒微圓，長四寸，此九針之長短也。

傷寒論、金匱要略方論用宋本通行條文；內經為素問、靈樞分篇；神農本草經用孫星衍輯本。本經疏證含鄒澍疏證、續疏、序疏要。臨證指南醫案按葉氏原門分案。醫學衷中參西錄為張錫純書，分醫方、藥物、醫論、醫話、醫案。金匱要略心典為尤怡注，分序、卷上、卷中、卷下；未收雜療、禽獸、果實三篇。溫病條辨為吳瑭書，分上中下焦，並雜說、解產難、解兒難。四聖心源為黃元御書。隨息居飲食譜為王士雄食療譜，分水飲、穀食、調和、蔬食、果食、毛羽、鱗介。供閱讀檢索，不是處方依據。
