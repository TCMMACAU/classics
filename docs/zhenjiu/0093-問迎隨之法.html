問迎隨之法

針灸大成 · 卷六

← 上一篇 下一篇 →

1經曰：隨而濟之是為補，迎而奪之是為瀉。夫行針者，當刺之時，用皮錢擦熟針。 復以口溫針熱，先以左手指爪，按其所刺榮俞之穴彈而努之，爪而下之，捫而循， 通而取之。令病人咳嗽一聲，右手持針而刺之，春夏二十四息， 先深後淺（其淺深之故註標幽賦內）。秋冬三十六息，先淺後深，徐徐而入， 氣來如動脈之狀，針下輕滑，未得氣者。若角之未吞鉤，既吞得氣，宜用補瀉， 補其經脈，推而按內之，停針一二時。稍久，凡起針，左手閉針穴，徐出針而疾按之。 瀉迎其經脈，提而動伸之，停針稍久，凡起針，左手開針穴，疾出針而徐按之。 補針左轉，大指努出，瀉針右轉，大指收入，補者先呼後吸，瀉者先吸後呼， 疼痛即瀉，痒麻即補。
