手少陰心經

針灸大成 · 卷八

← 上一篇 下一篇 →

1內經曰：心者君主之官，神明出焉。 心者身之本，神之變也。其華在面，其充在血脈，為陽中之太陽，通於夏氣。 南方赤色，入通於心，開竅於舌，藏精於心。故病在五臟，其味苦，其類火，其畜羊， 其穀黏，其應四時。上為熒惑星，是以知病之在脈也。其音徵，其數七，其臭焦， 其液汗。 南方生熱，熱生火，火生苦苦生心，心生血，血生脾，心主舌，其在天為熱， 在地為火，在體為脈，在臟為心，在聲為笑，在變動為憂，在志為喜，喜傷心， 恐勝喜，熱傷氣，寒勝熱，苦傷氣，鹹勝苦。

傷寒論、金匱要略方論用宋本通行條文；內經為素問、靈樞分篇；神農本草經用孫星衍輯本。本經疏證含鄒澍疏證、續疏、序疏要。臨證指南醫案按葉氏原門分案。醫學衷中參西錄為張錫純書，分醫方、藥物、醫論、醫話、醫案。金匱要略心典為尤怡注，分序、卷上、卷中、卷下；未收雜療、禽獸、果實三篇。溫病條辨為吳瑭書，分上中下焦，並雜說、解產難、解兒難。四聖心源為黃元御書。隨息居飲食譜為王士雄食療譜，分水飲、穀食、調和、蔬食、果食、毛羽、鱗介。供閱讀檢索，不是處方依據。
