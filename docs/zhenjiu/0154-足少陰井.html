足少陰井

針灸大成 · 卷七

← 上一篇 下一篇 →

1人病卒心痛，暴脹，胸□支滿，斯迺脈上貫肝膈，走於心內。故邪客於足少陰之絡， 而有是病。 可刺足少陰腎井湧泉，足心中刺三分，行六陰數，見血出，令人立飢欲食。 左取右，素有此病，新發刺五日愈，灸三壯。
