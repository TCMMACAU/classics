督任要穴圖 楊氏

針灸大成 · 卷九

← 上一篇 下一篇 →

1督脈 人病脊膂強痛，癲癇，背心熱，狂走，鬼邪，目痛，大椎骨痠疼，斯迺督脈起於下極， 並脊上行風府，起於尾閭，而生是病，可刺督脈人中穴，鼻柱下近孔陷中，針四分， 灸亦可，不及針，昏暈及癲狂者甚效。
2任脈 人病七疝八瘕，寒溫不調，口舌生瘡，頭項強痛，斯迺任脈起於中極下。 上毛循腹到關元，直至咽喉天突，過承漿而生是病，可刺任脈承漿穴，在髭間陷中， 刺人同身寸之三分，灸七壯，止七七壯。
