辨三關

針灸大成 · 卷十二

← 上一篇 下一篇 →

1凡小兒三關青，四足驚，三關赤，水驚，三關黑，人驚，有此通度三關候脈， 是急驚之症，必死，餘症可知。風關青如魚刺，易治，是初驚，色黑難治， 氣關青如魚刺，主疳勞身熱，易治，用八寶丹，每服加柴胡黃芩，色黑難治， 命關青如魚刺，主虛風邪附脾，用紫金錠，每服加白朮茯苓，色黑難治。風關青黑， 色如懸針，乃水驚，易治，氣關如懸針，主疳，兼肺臟積熱，保命丹，每服加燈心， 竹葉，命關有此是死症。風關如水字，主膈上有痰，并虛積停滯，宜下， 氣關如水字，主驚風入肺，咳嗽，面赤，用體前丹，命關如水字，主驚風疳症， 極力驚，用蘆薈丸，通過三關，黑色不治。風關如乙字，主肝驚風，氣關如乙字， 主急驚風，命關如乙字，主慢驚脾風，青黑難治。風關如曲蟲，主肝病積聚。

傷寒論、金匱要略方論用宋本通行條文；內經為素問、靈樞分篇；神農本草經用孫星衍輯本。本經疏證含鄒澍疏證、續疏、序疏要。臨證指南醫案按葉氏原門分案。醫學衷中參西錄為張錫純書，分醫方、藥物、醫論、醫話、醫案。金匱要略心典為尤怡注，分序、卷上、卷中、卷下；未收雜療、禽獸、果實三篇。溫病條辨為吳瑭書，分上中下焦，並雜說、解產難、解兒難。四聖心源為黃元御書。隨息居飲食譜為王士雄食療譜，分水飲、穀食、調和、蔬食、果食、毛羽、鱗介。供閱讀檢索，不是處方依據。
