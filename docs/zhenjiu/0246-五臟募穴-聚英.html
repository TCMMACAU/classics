五臟募穴 聚英

針灸大成 · 卷九

← 上一篇 下一篇 →

1中府（肺募）巨闕（心募）期門（肝募）章門（脾募）京門（腎募） 按難經云：陽病行陰，故令募在陰。（腹曰陰，募皆在腰。） 東垣曰：凡治腹之募，皆為原氣不足，從陰引陽，勿誤也。又曰：六淫客邪， 及上熱下寒，筋骨皮肉血脈之病，錯取於胃之合，及諸腹之募者必危。 五臟俞穴（俞猶委輸之輸言經氣由此而輸於彼也） 肺俞（三椎下各開寸半）心俞（五椎下各開寸半）肝俞（九椎下各開半） 脾俞（十三椎下各開寸半）腎俞（十四椎下各開寸半） 按難經云：陰病行陽，故令俞在陽。（背曰陽，俞皆在背，） 東垣曰：天外風寒之邪，乘中而入，在人之背上，腑俞臟俞，是人之受天外風邪， 亦有二說，中於陽則流於經，此病始於外寒，終歸外熱，收治風寒之邪， 治其各臟之俞。

傷寒論、金匱要略方論用宋本通行條文；內經為素問、靈樞分篇；神農本草經用孫星衍輯本。本經疏證含鄒澍疏證、續疏、序疏要。臨證指南醫案按葉氏原門分案。醫學衷中參西錄為張錫純書，分醫方、藥物、醫論、醫話、醫案。金匱要略心典為尤怡注，分序、卷上、卷中、卷下；未收雜療、禽獸、果實三篇。溫病條辨為吳瑭書，分上中下焦，並雜說、解產難、解兒難。四聖心源為黃元御書。隨息居飲食譜為王士雄食療譜，分水飲、穀食、調和、蔬食、果食、毛羽、鱗介。供閱讀檢索，不是處方依據。
