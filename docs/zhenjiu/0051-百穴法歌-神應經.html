1手之太陰經屬肺，尺澤肘中約紋是，列缺側腕寸有半，經渠寸口陷脈記， 太淵掌後橫紋頭，魚際節後散脈裏，少商大指內側尋，爪甲如韭此為的。 手陽明經屬大腸，食指內側號商陽，本節前取二間定，本節後勿三間忘， 歧骨陷中尋合谷，陽谿腕中上側詳，三里曲池下三寸，曲池曲肘外輔當， 肩□肩端兩骨覓，五分俠孔取迎香。（□音魚） 足陽明兮胃之經，頭維本神寸五分。頰車耳下八分是，地倉俠吻四分臨， 伏兔陰市上三寸，陰市膝上三寸針，三里膝下三寸取，上廉里下三寸主， 下廉上廉下三寸，解谿腕上繫鞋處。衝陽陷谷上二寸，陷谷庭後二寸舉， 內庭次指外間求，厲兌如韭足次指。 足之太陰經屬脾，隱白大指內角宜，大都節後白肉際，太白後一下一為， 公孫節後一寸得，商邱踝下前取之，內踝三寸陰交穴，陰陵膝內輔下施， 手少陰兮心之經，少海肘內節後明，通里掌後絻一寸，神門掌後銳骨精。 手太陽分小腸索，小指之端取少澤，前谷外側本節前，後谿節後仍外側， 腕骨腕前起骨下，陽谷銳下腕中得，小海肘端去五分，聽宮耳銖如菽側， 太陽膀胱何處看，睛明目眥內角畔，攢竹兩眉頭陷中，絡卻後髮四寸半。 肺俞三椎膈俞七，肝俞九椎之下按，腎俞十四椎下旁，膏盲四五三分算， 委中膝膕約紋中，承山□下分肉斷，崑崙踝下後五分，金門踝下陷中撰， 申脈踝下筋骨間，可容爪甲慎勿亂。（□音善） 少陰腎兮安所覓，然谷踝前骨下識，太谿內踝後五分，照海踝下四分的， 復溜內踝上二寸，向後五分太谿直，手厥陰兮心包絡，曲澤肘內橫紋作， 間使掌後三寸求，內關二寸始無錯，大陵掌後兩筋間，中衝中指之端度。 手少陽兮三焦論，小次指間名液門，中渚次指本節後，陽池表腕有穴存， 脘後二寸外關絡，支溝腕後三寸間，天井肘上一寸許，角孫耳廓開口分， 絲竹眉後陷中按，耳門取缺非虛文。 足少陽膽取聽會，耳前陷中分明揣，目上入髮際五分，臨泣之穴於斯在， 目窗泣上寸半存，風池髮後際中論，肩井骨前看寸半，帶脈肋下寸八分， 環跳髀樞尋宛宛，風市髀外兩筋顯，陽陵膝下一寸求，陽輔桌上四寸遠， 絕骨踝上三寸從，邱墟踝前有陷中。臨泣俠谿後寸半，俠谿小次歧骨縫， 厥陰肝經果何處，大敦拇指有毛聚，行間骨尖動脈中，太衝節後有脈據， 中封一寸內桌前，曲泉紋頭兩筋著，章門臍上二寸量，橫取六寸著兩旁， 期門乳旁一寸半，直上寸半二肋詳。 督脈水溝鼻柱下，上星入髮一寸者，百會正在頂之巔，風府後髮一寸把， □門後髮際五分，大椎第一骨上存，腰俞二十一椎下，諸君仔細詳經文。 任脈中行正居腹，關元臍下三寸錄，氣海臍下一寸半，神闕臍中隨所欲， 水分臍上一寸求，中腕臍上四寸取，膻中兩脬中間索，承漿宛宛唇下搜。病人閱讀頁
